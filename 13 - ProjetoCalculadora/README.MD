# 13 - Projeto Calculadora

## 📚 O que aprendi

Neste projeto desenvolvi uma calculadora em C# utilizando os conceitos aprendidos nas aulas anteriores.

O programa funciona através de um menu interativo no console, onde o usuário escolhe uma operação matemática e o sistema executa o cálculo correspondente.

Foi o primeiro projeto em que utilizei vários conceitos juntos para criar uma aplicação completa.

## 💻 Funcionalidades

A calculadora possui as seguintes opções:

- ➕ Soma
- ➖ Subtração
- ➗ Divisão
- ✖️ Multiplicação
- 🔢 Potência
- √ Raiz Quadrada
- 🚪 Sair do programa

Após realizar uma operação, o programa retorna ao menu principal até que o usuário escolha a opção **Sair**.
