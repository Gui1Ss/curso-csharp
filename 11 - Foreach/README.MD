# 11 - Foreach

## 📚 O que aprendi

Nesta aula aprendi a utilizar o `foreach` em C#.

O `foreach` é utilizado para percorrer os elementos de uma coleção, como um array.

## 💻 Exercício

Neste exercício criei um array chamado `palavras` contendo algumas strings:

```csharp
string[] palavras =
{
    "Guilherme",
    "Curso c#",
    "Palmeiras",
    "Animes",
    "Carros"
};
