## 📌 Sobre

Repositório de estudos com os exercícios do curso **"C# para iniciantes — Crie 4 projetos"**, de *Victor Lima (Guia do Programador)*.

Cada pasta é um projeto de console independente, com um `README.md` próprio explicando **o conceito**, **o código comentado**, **a saída esperada** e os **erros que cometi pelo caminho** — porque o que eu errei costuma ensinar mais do que o que acertei de primeira.

## 🚀 Como executar

**Pré-requisitos:** [Visual Studio 2022](https://visualstudio.microsoft.com/) com a carga *Desenvolvimento para desktop com .NET* e o [.NET Framework 4.7.2 Developer Pack](https://dotnet.microsoft.com/download/dotnet-framework/net472).

```bash
git clone https://github.com/Gui1Ss/curso-csharp.git
cd curso-csharp
```

Abra o arquivo `.slnx` do módulo desejado e execute com `F5` (com depuração) ou `Ctrl + F5` (sem depuração).

> 💡 Cada módulo é independente — não é preciso abrir os anteriores para rodar um projeto específico.
